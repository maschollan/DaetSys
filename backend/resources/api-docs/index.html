Buka OpenAPI JSON Cek Health
Cara memakai halaman ini:
  1. Buka grup endpoint di menu kiri, lalu pilih endpoint yang ingin dicoba.
  2. Scroll ke bagian Test Request — form parameter akan terisi otomatis sesuai skema.
  3. Isi kolom Value, lalu tekan Send Request untuk melihat status, waktu respons, dan isi body.
  4. Untuk endpoint terlindungi, masukkan token pada bagian Authentication di atas: klik Bearer lalu isi token hasil POST /api/login.

Dokumentasi tidak dapat dimuat

Gagal mengambil dokumen OpenAPI dari /docs/api.json. Pastikan aplikasi sedang berjalan dan Anda memiliki akses ke dokumentasi API.
